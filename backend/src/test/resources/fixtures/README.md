# Fixtures de materiais

`legacy-aula.pps` é uma apresentação binária OLE2 válida, gerada exclusivamente
para testes pelo Apache POI HSLF. Ela contém texto didático sintético e não deriva
de material escolar ou privado.

A fixture comprova que o caminho legado aceita um arquivo físico `.pps`, preserva
seus bytes e entrega o conteúdo ao HSLF; não é apenas um nome de arquivo simulado
nem um arquivo textual renomeado.
