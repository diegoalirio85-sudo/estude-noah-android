# Estratégia de Testes

## Build
Toda alteração deve compilar no GitHub Actions.

## Regressão
Testar:
- abrir app;
- Área dos Pais;
- material;
- apagar extração;
- salvar atividade;
- executar;
- histórico;
- fechar/reabrir;
- atualização do APK sem perda de dados.

## Pedagógicos
Usar materiais fixos por matéria e avaliar literalidade, ambiguidade, cobertura temática, falsas plausíveis, fidelidade e dificuldade.

## Dispositivo real
O tablet Samsung é o ambiente final de aceitação.
