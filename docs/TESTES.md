# Estratégia de Testes

## Build
Toda alteração deve compilar no GitHub Actions.

## Regressão
Testar:
- abrir app;
- Área dos Pais;
- material;
- apagar extração;
- salvar atividade;
- executar;
- histórico;
- fechar/reabrir;
- atualização do APK sem perda de dados.

## Pedagógicos
Usar materiais fixos por matéria e avaliar literalidade, ambiguidade, cobertura temática, falsas plausíveis, fidelidade e dificuldade.

## Dispositivo real
O tablet Samsung é o ambiente final de aceitação.


## Resposta matemática

Cobrir campo “Sua resposta”, bloqueio da solução antes da tentativa, equivalência numérica e decimal, erro, avaliação indeterminada segura, persistência opcional das tentativas e leitura retrocompatível do histórico sem o campo `answers`. Confirmar também que Verdadeiro/Falso mantém o fluxo existente.
