# Processo de Releases

## Fluxo
Branch → implementação → testes → Pull Request → GitHub Actions → revisão → merge → APK → teste no tablet.

## Baseline
Preservar o commit estável atual com tag semelhante a:
`v3.3-stable-pre-migration`

A tag deve apontar para o commit do APK efetivamente testado.

## Assinatura
Preservar chave/configuração atual até existir plano explícito de migração.

## Versionamento
A numeração futura será definida após ler o estado real do repositório.
